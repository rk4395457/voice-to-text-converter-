# 🎤 Voice to Text Converter

A simple and responsive Voice to Text Converter built using HTML, CSS, and JavaScript. This application uses the Web Speech API to convert spoken words into text in real time.

## 🚀 Features

- Real-time speech-to-text conversion
- Start and stop voice recognition
- Clean and user-friendly interface
- Responsive design
- Fast and accurate transcription

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Speech API

## ▶️ How to Run

1. Download or clone the repository.
2. Open `index.html` in your browser.
3. Click the Start button and begin speaking.
4. Your speech will be converted into text instantly.
